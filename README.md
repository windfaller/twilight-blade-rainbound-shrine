# TWILIGHT BLADE: RAINBOUND SHRINE

**暮刃紀行：雨鎖山門** — 可完整通關的瀏覽器 2.5D/3D 動作 RPG 垂直切片。

雨夜山門、濕石、金燈與殘月。六名刃客、守燈祝福、三場遭遇、會改寫下一戰的遺物、精英與兩階段頭目「雨蝕武者」。

## 執行

```bash
npm i
npm run dev
```

瀏覽器開啟終端機顯示的本機網址（預設 `http://localhost:5173`）。

```bash
npm run build
npm run preview
```

預覽預設 `http://localhost:4173`。

```bash
npm test
npm run lint
```

## 通關路徑

載入（真實進度＋失敗可重試）→ 主選單 → 操作／設定 → 六刃選擇（選卡即載入該套）→ 雨鎖山門 3D 探索 → 與守燈人對話取得祝福 → 祭壇三場遭遇 → 每場後三選一遺物（必然改寫下一戰）→ 精英 → 兩階段雨蝕武者 → 勝／敗、解鎖、可重玩。

**不會**在第一擊擊殺後結束。

## 已完成

- React + TypeScript + Vite + Three.js r170、WebGL2、DOM UI + canvas
- 模擬狀態獨立於 mesh／React DOM；固定步進＋插值
- 真實 3D 地面、石階、鳥居、石燈、斷橋、牆、可行走區、遮擋物、燈光、雨霧、遠景 farscape（僅作遠景）
- 戰術等距 35–45°、縮放、有限旋轉回正、遮擋淡出
- 六套相異技能、層級骨骼紙人動畫（腿、髖、髮、襬、兵器會動，不是滑靜幀）
- 完整戰鬥反饋：起手、刀光、hitstop、受擊、數字、粒子、音效、震動、擊退
- 遺物數值生效（浪刃、完美迴避分身、狐火治療、CDR、殘血盾、大招元素、暴擊破勢、撞牆加成）
- 頭目第二階段：暴雨、外觀切換、鬼青刀、破壞場地、可行走改變、新招式與音樂提示
- 中文介面、16px／行動 17px、觸控 ≥44px、戰鬥中鎖頁面捲動
- 品質高／中／低、Web Audio 分軌合成（非單聲 beep）
- 除錯層預設關（F3）：座標、路徑、FPS、drawcalls
- 測試：戰鬥／遺物／存檔／尋路
- 官方立繪與場景圖已提交於 `public/assets/`，並有 `manifest.json`

## 已知限制

- 沒有 8 向影片 sprite sheet；以分層骨骼驅動官方立繪。
- 濕地反射以材質金屬度／粗糙度與品質設定近似，而非完整平面反射探針。
- 音樂與音效為分層 Web Audio 合成，非預錄樂團。
- 垂直切片只含雨鎖山門一條連貫路線，沒有開放世界。
